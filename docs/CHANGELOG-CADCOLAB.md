# Changelog CadColab

## Em desenvolvimento — 4.0

- Editor de configurações do e-mail de recuperação, restrito ao perfil TI.
- Persistência na tabela configuracoes e auditoria de alterações.
- Pré-visualização visual em tempo real, com identidade ENFAS e exemplo de link Autoatendimento.
- Instalação incremental sem substituir o painel existente.

- Integração ao menu Configurações Mestres da versão instalada.
- Editor HTML rico com sanitização, versionamento e envio de teste.
- Consumo dos modelos pelo Autoatendimento e recuperação integrada ao Microsoft 365.
- Testes de autorização, persistência e segurança em produção.
